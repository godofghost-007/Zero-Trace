1. Executive Summary & Philosophy

ZeroTrace is an open-source, zero-cost, CPU-optimized cyber defense platform combining three modular traces into a single source of truth:

  • Trace 1 (RECON): Attack Surface Discovery (Subdomains, Ports, S3 buckets, SSL expiry, Shadow IT).
  • Trace 2 (INTEL): AI-Powered Vulnerability Prioritization (NVD + EPSS, XGBoost Exploit Model, Ollama Auto-Fix).
  • Trace 3 (GUARD): LLM Security Middleware Gateway (Regex pre-filter, ONNX DistilBERT classifier, PII scanner, Hash-chained SQLite audit log).
Operational Readiness Score (v2.0 Fixed) = 100 - (0.40 × Asset Exposure + 0.40 × Vuln Urgency + 0.20 × AI Threat Exposure Index)
